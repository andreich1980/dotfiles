# Codebase Structure

**Analysis Date:** 2026-05-11

## Directory Layout

```
[project-root]/
├── git/            # Git configuration
├── vim/            # Vim configuration
├── zsh/            # Zsh configuration
├── install         # Bash installation script
└── install.ps1     # PowerShell installation script
```

## Directory Purposes

**git/:**
- Purpose: Contains Git-related configuration.
- Contains: Global gitconfig.
- Key files: `git/.gitconfig`

**vim/:**
- Purpose: Contains Vim-related configuration.
- Contains: Vimrc settings.
- Key files: `vim/.vimrc`

**zsh/:**
- Purpose: Contains Zsh-related configuration additions.
- Contains: Custom aliases and shell settings.
- Key files: `zsh/.zshrc_local`

## Key File Locations

**Entry Points:**
- `install`: Primary entry point for Unix/macOS/Linux systems.
- `install.ps1`: Primary entry point for Windows systems.

**Configuration:**
- `git/.gitconfig`: Global Git configuration.
- `vim/.vimrc`: Global Vim configuration.
- `zsh/.zshrc_local`: Custom Zsh configuration.

**Core Logic:**
- `install`: Bash logic for symlinking and file modification.
- `install.ps1`: PowerShell logic for symlinking and file modification.

**Testing:**
- Not detected: No automated tests for the installation scripts are present.

## Naming Conventions

**Files:**
- [Standard Config Names]: Config files use their standard tool names (e.g., `.gitconfig`, `.vimrc`).
- [Entry Points]: Installation scripts are named `install` with appropriate extensions.

**Directories:**
- [Tool-based]: Directories are named after the tool they configure (e.g., `git`, `vim`, `zsh`).

## Where to Add New Code

**New Tool Configuration:**
1. Create a new directory named after the tool (e.g., `tmux/`).
2. Add the configuration file inside (e.g., `tmux/.tmux.conf`).
3. Update `install` and `install.ps1` to handle the new symlinking logic.

**New Aliases/Shell Helpers:**
- Add to `zsh/.zshrc_local` for Zsh/Unix environments.
- (Recommended) Add to `powershell/PowerShell_Local.ps1` (if directory is created) for Windows environments.

**Utilities:**
- Shared helper scripts can be added to a new `bin/` or `utils/` directory.
