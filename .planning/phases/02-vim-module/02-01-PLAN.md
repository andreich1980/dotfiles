Implement the Vim module to manage Vim configuration using a shared source pattern. This ensures that the user's main .vimrc is preserved while including the managed configuration, and that Vim's persistent state files are stored in a dedicated directory structure. Additionally, provide support for JetBrains IDEs by symlinking .ideavimrc.
</objective>

<task type="auto">
  <name>Task 1: Update Vim shared configuration</name>
  <files>vim/.vimrc</files>
  <action>
    Update the existing 'vim/.vimrc' file to include centralized state management settings. 
    Ensure persistent state (undo, backup, swap) is stored in '~/.vim/'.
    
    Add or update these settings:
    ```vim
    set undofile
    set undodir=~/.vim/undo//
    set backup
    set backupdir=~/.vim/backup//
    set directory=~/.vim/swap//
    ```
    Remove any conflicting settings like 'set backupdir-=.'.
  </action>
  <verify>
    <automated>grep -q "undodir=~/.vim/undo//" vim/.vimrc</automated>
  </verify>
  <done>Vim configuration updated with centralized state management settings.</done>
</task>

<task type="auto">
  <name>Task 2: Implement Vim module</name>
  <files>modules/vim.sh</files>
  <action>
    Create 'modules/vim.sh' following the pattern established in 'modules/git.sh' and the instructions in '02-RESEARCH.md'.
    
    The module should:
    1. Define VIMRC_SHARED as '$HOME_DIR/.vimrc_shared'.
    2. Define VIMRC_MAIN as '$HOME_DIR/.vimrc'.
    3. Define IDEAVIMRC as '$HOME_DIR/.ideavimrc'.
    4. Back up VIMRC_MAIN using 'backup_file'.
    5. Link 'vim/.vimrc' to VIMRC_SHARED using 'safe_link'.
    6. Include 'source ~/.vimrc_shared' in VIMRC_MAIN using 'include_line'.
    7. Link 'vim/.ideavimrc' to IDEAVIMRC using 'safe_link'.
    8. Create '~/.vim/undo', '~/.vim/backup', and '~/.vim/swap' using 'run mkdir -p'.
    
    Ensure it uses '$DOTFILES_DIR' and '$HOME_DIR' exported from 'install'.
  </action>
  <verify>
    <automated>test -f modules/vim.sh && chmod +x modules/vim.sh && bash -n modules/vim.sh</automated>
  </verify>
  <done>Vim module script implemented and syntax-checked.</done>
</task>
